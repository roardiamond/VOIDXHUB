# VOIDXHUB

**Official website and platform for VOIDXHUB** – a modern gaming utilities and tournament management ecosystem.

🌐 Live: [voidxhub.in](https://voidxhub.in)

## Overview

VOIDXHUB is a full-stack platform designed for the gaming community, offering:

- Clean, responsive web interface
- Tournament and scrim management
- User authentication and order system
- Admin tools for platform management
- Mobile-friendly design with dark neon aesthetic

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Hosting**: GitHub Pages / Custom domain
- **Backend Integration**: Connected with voidxhub-backend (Python)

## Features

- Device and game selection UI
- Dashboard for users
- Tournaments listing and registration
- Premium tools catalog
- Responsive design optimized for mobile and desktop
